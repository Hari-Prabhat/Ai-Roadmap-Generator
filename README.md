# Ai-Roadmap-Generator
AI-based roadmap generator using ML

An intelligent web-based system that generates personalized learning roadmaps using Machine Learning, Natural Language Processing, and similarity matching.

The system analyzes user goals and skills to recommend structured learning paths and allows users to download their roadmap as a PDF.

---

## 📌 Overview

The AI Powered Learning Roadmap Generator helps learners plan their learning journey efficiently by providing customized roadmaps.

It uses TF-IDF vectorization and cosine similarity to match user inputs with predefined learning paths stored in a dataset.

The application is built using Streamlit for UI, MySQL for feedback storage, and ReportLab for PDF generation.

---

## ✨ Features

- 🤖 AI-based roadmap recommendation
- 📊 TF-IDF + Cosine Similarity matching
- 💻 Interactive Streamlit web interface
- 📥 Download roadmap as PDF
- 🗂️ Excel-based dataset integration
- 📝 User feedback system with MySQL
- 🔄 Multiple recommendation suggestions

---

## 🛠️ Tech Stack

- Programming Language: Python
- Frontend/UI: Streamlit
- Machine Learning: Scikit-learn (TF-IDF, Cosine Similarity)
- Data Handling: Pandas
- Database: MySQL
- PDF Generation: ReportLab
- Dataset Format: Excel (.xlsx)
